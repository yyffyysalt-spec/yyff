# 批量抠图 + 高清放大网页工具

这是一个纯前端版本，直接在浏览器里完成批量上传、基础抠图、放大、预览和下载，不需要先安装依赖。

## 怎么打开

直接双击打开 `index.html`，或把这个文件拖到浏览器窗口里。

## 怎么使用

1. 点击上传区域，或把多张图片拖进页面。
2. 选择处理模式：`抠图 + 放大`、`只抠图`、`只放大`。
3. 选择抠图模型，并调整放大倍数、背景容差、边缘柔化、边缘收缩、背景颜色。
4. 点击 `开始处理`。
5. 单张结果可点击结果图放大预览，也可点 `编辑` 进入编辑区；全部结果可点左侧下载图标打包为 ZIP。

## 当前适合的图片

这个版本使用浏览器本地算法，适合白底、浅色底、纯色背景、商品图、头像等边界比较明确的图片。

如果抠图后有白边、灰边或底色残留，可以把 `边缘收缩` 调到 `轻微` 或 `明显`；如果主体被吃掉，就调回 `不收缩`。

主体颜色和背景相近时，优先使用 `本地精细`；如果背景仍有残留，再切到 `本地强力`、`BiRefNet 通用` 或 `RMBG-2.0 精抠`，并适当提高 `背景容差`。

`背景颜色` 默认是透明。选择白色、黑色或自定义颜色后，下载结果会直接带这个背景色。

处理完成后点单张图片的 `编辑`，可以在编辑区使用 `智能拾取` 或 `钢笔抠除`。`智能拾取` 适合点掉同色残留，`吸管容差` 越高，单次拾取覆盖的相近颜色范围越大；`钢笔抠除` 适合像 PS 一样圈选边缘残留区域，点满 3 个以上路径点后点 `完成路径`。

`边缘强度` 会影响编辑区二次抠除后的边缘过渡。数值越高，残留边缘会被处理得更明显；如果主体边缘被吃掉，可以把它调低。误删时可点 `撤销`，钢笔路径画错可点 `清除路径`。

编辑区会自动把图片完整适配到可视区域内，方便看到整个抠出物体；这只影响显示，不改变最终导出的真实尺寸。

在编辑区中，鼠标滚轮可放大/缩小，按住鼠标拖动可移动画面；键盘 `+` / `-` 可缩放，方向键可上下左右移动，`0` 可恢复完整适配显示。

如果图片是复杂场景、头发丝、半透明玻璃、杂乱背景，建议下一步接入 AI 抠图模型或第三方 API。前端已经把上传、队列、预览、下载流程做好，后续可以根据 `app.js` 里的 `model` 值，把 `removeBackground` 和 `upscaleCanvas` 替换成接口调用。

## 推荐的生产级模型

- 通用商品图、物体图：BiRefNet Lite 速度更快，BiRefNet 通用版更干净。
- 电商精抠、边缘要求高：BRIA RMBG-2.0。
- 人像、半身照、直播头像：MODNet，速度快，但主要适合人像。
- 高清放大：Real-ESRGAN 更通用，Swin2SR 在部分真实退化图片上质量更好。

如果要做成真正商用批量工具，建议前端保持现在的队列和下载流程，后端增加 `/api/remove-background` 和 `/api/upscale` 两个接口，把抠图和放大交给 GPU 服务处理。

## 下一步增强方向

- 接 AI 抠图：remove.bg、Clipdrop、Replicate、或自建 RMBG/SAM 服务。
- 接 AI 高清放大：Real-ESRGAN、SwinIR、Topaz/第三方商业 API。
- 增加后台任务：适合几十张以上的大批量处理。
- 增加参数模板：商品白底、证件照、头像、透明边距等。
